# AIツール早見表

やりたいこと別に、まず試したいAIツールをまとめました。機能や利用条件は更新されることがあるので、使う前に各サービスの公式情報も確認してください。

| やりたいこと | おすすめ | ひとこと |
| --- | --- | --- |
| いろいろ相談・文章作成 | [ChatGPT](https://chatgpt.com/) | まず気軽に試せる万能アシスタント。画像生成にも使える |
| 長文の読解・文章の相談 | [Claude](https://claude.ai/) | 資料を読ませたり、考えを整理したりするときの候補 |
| コード作業をエージェントに任せる | [OpenCode](https://opencode.ai/) | ターミナル中心で使うオープンソースのコーディングエージェント |
| 動画生成 | Seedance | テキストや画像から動画を作りたいときに |
| 画像生成 | ChatGPT | 会話で指示しながら画像を作ったり、修正したりできる |

## まずはこの組み合わせ

- **普段使い**：ChatGPT
- **文章や資料をじっくり扱う**：Claude
- **開発作業を進める**：OpenCode
- **動画を作る**：Seedance
- **画像を作る**：ChatGPT

## エージェントAIの使い分け

エージェントAIは、目的を伝えると複数の手順を進めてくれるAIです。調査、文章の下書き、コードの変更など、作業のまとまりを頼むと便利です。

- **ChatGPT**：調べものや文章作成など、幅広い作業の相談窓口に。
- **Claude**：長めの文章や資料を読ませて、要約や整理を頼むときに。
- **OpenCode**：コードベースを扱う開発作業に。変更内容を確認してから反映するのがおすすめです。

## 動画・画像生成のコツ

作りたいもの、雰囲気、長さや画角、入れたい要素を具体的に伝えると、イメージに近づけやすくなります。最初から完璧を狙わず、出力を見て「ここをこう変える」と追加で指示していくのがコツです。

例：

> 夕方の海辺を歩く白い犬。映画のワンシーンのような自然な光、ゆっくりしたカメラ移動、縦長動画。

画像も同じように、主役・場所・画風・構図を伝えてから、気になる箇所を会話で調整します。

## 選ぶときのポイント

- まず無料枠や試用範囲で、自分の用途に合うか確認する。
- 機密情報や個人情報を入力する前に、各サービスのデータ取り扱いを確認する。
- AIの出力は間違うことがあるため、事実やコードは必要に応じて確認する。
- 料金、使える地域、機能は変わることがあるので、公式サイトで最新情報を確認する。
