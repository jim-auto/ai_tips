01 / Agents

エージェントAI

会話で答えるだけでなく、道具を使って作業を進めるAI。

まず試す

Claude Code

代表的なコーディングエージェント。作業フォルダのファイルを読み、整理・検索・集計し、必要ならスクリプトやレポートも作れる。

Claude Pro $20/月（米国価格目安）。利用上限・地域価格は要確認。

クラウドで作業

Grok Bot

クラウド上のAIチームメイト。タスクを委任し、継続する作業や自動化を進める用途。利用枠は他のGrok機能と共有。

Premium $30/月からBot利用。プラン・提供地域を要確認。

開発エージェント

OpenCode

オープンソースのコーディングエージェント。モデルを選んでリポジトリの調査や修正を頼める。コスパ重視ならDeepSeek Flashを候補に。

本体無料。OpenCode Go $10/月、Go Plus $40/月、またはAPI従量課金。

パーソナルエージェント

Meta Muse

連携アプリやブラウザを使って、日常の用事や目標達成を手伝うタイプ。無料枠あり、現時点では米国から提供開始。

文章・相談

Google Gemini / Argon

Argonは文章力が高いという評判を聞く。自分ではまだあまり使っていないので、ここは未評価メモ。

普段使い

ChatGPT / Claude

相談、文章、資料の読解など。エージェント機能の範囲はプランや提供状況によって変わる。

ChatGPT Plus / Claude Pro ともに $20/月（米国価格目安）。

任せやすい仕事

ファイルを整理する

フォルダの中身を一覧化し、ファイル名や内容から分類案を作る。まず読み取りと提案だけ頼み、確認してから移動・改名する。

ネットの情報を集める

調べるテーマ・期間・情報源を指定。複数ページの要約、共通点と違い、出典リンクを表にまとめてもらう。

データを解析する

CSVなどを読み、欠損や傾向を確認。月次集計、グラフ、分析メモを作る。指標の定義と対象期間も伝える。

資料やコードを扱う

複数文書から議事録や比較表を作る。コードの調査・修正・テストも、変更理由と差分を見ながら進める。

依頼文の例

目的＋対象＋条件＋成果物
「資料/2026のPDFとCSVから売上の月次傾向をまとめてください。最初に対象ファイル一覧と分析方針を出してください。ファイル移動・削除・外部送信はしないでください。最後に出典ファイル名付きのMarkdownレポートと集計CSVを作ってください。」
02 / Automation

自動化コーナー

画面操作は専用ツールに任せ、AIは手順作成や結果の確認を担当。

Web

Playwright

ブラウザ操作、フォーム入力、スクリーンショット、E2Eテストに。繰り返し作業はスクリプト化し、ラベルやロールで要素を指定すると壊れにくい。

Android

ADB（Android Debug Bridge）

端末・エミュレーターでアプリを起動したり、ログや画面を取得したりするコマンドラインツール。端末でUSBデバッグを有効にして接続を許可する。

Android端末の操作なら通常は adb。gdb は主にネイティブコードのデバッグに使う別ツール。

手順を決める

対象、成功条件、触ってよい範囲をAIに整理してもらう。

自動化する

PlaywrightやADBなど、目的に合う道具で再現可能な手順にする。

結果を検証する

期待した表示やデータになったか確認し、ログや画像を残す。

AIに依頼を断られたら
古いモデルや別AIで安全制限を回避するのではなく、目的・権限・対象を具体的に説明し、読み取りや提案など安全な小さい段階から頼む。正当な作業でも権限や利用規約に反する操作は行わず、管理者承認や許可済みの方法を確認する。
03 / Image

画像生成AI

画像を作る用途は、動画生成とは別に選ぶ。

おすすめ

Google Nano Banana

Googleの画像生成モデル。作りたい画像を会話で説明し、出力を見ながら修正する用途に。

手軽さ

ChatGPT Images

会話の流れで画像を生成し、部分修正を頼みやすい。無料枠や生成上限はプランにより変わる。

Plus $20/月（米国価格目安）。

プロンプトには「主役・場所・画風・構図・用途」を入れる。文字入り画像は、生成後に表記を確認する。

04 / Video

動画生成AI

短い試作を作り、指示を直して仕上げる。

おすすめ

Seedance

テキストや画像から動画を生成。Dreaminaなど提供サービスのプランやクレジットで利用条件が異なる。

Dreamina Basic $15/月からの表示例。地域・キャンペーン・継続価格を要確認。

動画プロンプトの型

主役、動き、場所、時間・光、カメラの動き、画角、長さを指定する。

例：夕方の海辺を歩く白い犬。自然な逆光、ゆっくり追従するカメラ、縦長、5秒。

生成前に設定ごとのクレジット消費を確認。再生成する回数も含めて予算を考える。
