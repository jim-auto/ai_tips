01 / Agents

エージェントAI

自立型パーソナルエージェントと、コーディングエージェントを使い分ける。

料金の選び方：エージェント系は利用量が増えると従量課金が割高になりやすいので、基本はサブスクがおすすめ。従量課金と比べて、サブスクは約10倍コスパが良いとする比較レポートもある（条件によって差がある）。

自立型パーソナルエージェント

どちらが向く？非エンジニアが秘書のように相談し、調査・予定・日常の用事を任せたいなら、パーソナルエージェントは始めやすい。Claude Codeのように複数セッションを分けて並行作業したい、コードやファイルを直接扱いたいならコーディングエージェントが向く。

自分はChatGPT dotとMuseに、メール送信やカレンダーの予定通知などを頼んでいる。違いはまだはっきり分からない。個人情報を広く預け、買い物まで自動化する使い方もあるらしいが、自分はそこまで任せるのは慎重。ChatGPTはPlus $20/月、Pro $100・$200・$500/月（米国目安）。Grok BotはPremium（月$30）以上。

コーディングエージェント

名前に「コーディング」と付くが、コード専用ではない。PC上のファイル整理、Web情報の収集・比較、CSV解析、文書作成などの雑務もこなせる。以前は「ターミナル」という黒い画面を使う場面が多かったが、最近はブラウザ版やアプリからも使え、入口のハードルは下がった。Claude CodeとCodexはクラウド上で開発タスクを実行できる機能もあり、自分のPCに開発環境を用意せず、ブラウザやアプリから依頼・確認できる。それでも、非エンジニアにはまだ利用者が少ない印象。

高性能

Claude Code

個人の所感では、Opus 5.5は現環境の覇者。セキュリティチェックが厳しく、グレーな依頼は断られやすい。

Claude Pro $20/月、Max $100・$200/月（米国目安）。

高性能

Codex

日本語は少し不自由に感じることがある。一方、週間利用制限がリセットされるので、コスパは良い印象。

ChatGPT Plus $20/月、Pro $100・$200・$500/月（米国目安）。使える量はプラン・モデル・作業内容で変わる。上限後はリセットを待つか追加クレジット。APIキー利用は従量課金。

低価格

OpenCode ＋ DeepSeek Flash

複数のAIモデルを切り替えて使える開発エージェント。おすすめモデルは、低価格で実用性も高いDeepSeek Flash。

OpenCode Go $10/月、Go Plus $40/月、Teams $20/人。個人の所感では$10でもかなり使える。

料金の目安：ClaudeとCodexは月20ドルだと物足りなく感じる。開発タスクをかなり並列で回さない限り、月100ドルで十分だと思う。自分はOpus 5.5を使いたくてClaudeに月200ドル、Codexは開発負荷に応じて契約。Opus 5.5が出る前はCodexに月200ドルを使い、Claudeを解約していた時期もある。必要なモデルや契約先は時期で変わるので、固定せず見直す。

所感：高性能エージェントは Claude Code と Codex の二強。今は Claude Code が強く感じるが、両者が切磋琢磨している。簡単な作業や一般ユーザーには、ここまでの性能が不要なことも多い。

活用例：ファイル分類 / Web情報の要約・比較 / CSV解析 / レポート作成

Google Argonは文章力が高いとの評判。自分ではまだ未評価。

02 / Automation

自動化

自動化ツールはAIそのものではなく、AIと組み合わせて使うソフトウェア。

AIにスクリプト作成や手順の提案を頼み、PlaywrightやADBが実際の操作を実行する。

Web

Playwright

ブラウザ操作・フォーム入力・画面テストを自動化。

Android

ADB

端末操作・アプリ起動・ログ取得。さらに自由度を求めてAPIを直接使う方法もあるが、高度な操作ではroot化が必要な場合もあり難易度は高め。

iPhoneはセキュリティが高く、初心者が自動化する難易度は高め。Android端末操作なら通常は adb。

AIが断ったら：モデルによって制限の判定には差があり、別モデルを使ったり、目的を直接言わず周辺的に表現したりすると通ることがある。

04 / Video

動画生成

おすすめはSeedance。現状一強で、動画の品質も群を抜いている印象。

Seedance

ByteDance（TikTokの親会社）が開発。テキストや画像から動画を生成。

所感：AI動画で有名な INMU KING などの作例でもSeedanceの利用が話題。2026年11月現在、周囲でも使う人が多く、品質は群を抜く印象。

元作品の使用モデルは公開情報だけでは確認できない場合があります。動画生成は処理が重く、他のAIサービスよりコストが高くなりがちなので注意。筆者は動画生成を本格的に試していないため、評価は参考程度。
